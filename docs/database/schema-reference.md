# Schema reference

All 63 tables, by module. The source of truth is `packages/database/prisma/schema.prisma` and the migrations. The design is section 3 of [the step 1.1 design](../plan/steps/01-database.md#3-data-model); steps 1.2 + 1.3 added two identity tables and the identity/tenancy columns ([D10](../plan/steps/02-tenants-auth-rbac.md#d10-data-model-changes-one-forward-migration-wp1), migration `20261102061337_identity_tenancy`); step 2.1 added the domain lifecycle, DNS-check and DKIM key-custody columns ([§3](../plan/steps/03-domain-onboarding.md#3-data-model-one-forward-migration-wp1), migration `20261102091717_domain_onboarding`, plus the data-only `20261102110046_domain_check_backfill` that schedules pre-2.1 domains for their first check). Diagrams are in [er-diagram.md](er-diagram.md), and index rationale in [indexing.md](indexing.md).

Legend:

- Every table has `id BIGINT UNSIGNED AUTO_INCREMENT` unless stated, and `created_at` (plus `updated_at` on mutable rows).
- **org** = `organization_id BIGINT UNSIGNED NOT NULL` with a foreign key to `organizations` (none on partitioned tables). **org?** = nullable (NULL means platform-level).
- **P** = partitioned (column, granularity); see [partitioning.md](partitioning.md). Retention tiers are in [retention.md](retention.md).
- **Owner** = the deployable that writes the table ([data ownership](../architecture/data-ownership.md)). Every service writes `message_idempotency` (through `processOnce`) and `message_outbox`.
