# Chat testing report (step AI-1)

What was tested for the AI assistant in step AI-1, with the results of the WP6 verification run on 2026-11-20 (local stack, branch `build/platform` on `46d5d94` plus the uncommitted AI-1 working tree). Test plan: [design §9](../plan/steps/28-ai-chat-management.md#9-test-plan); full verification record: design note §13.

**No test reaches an LLM or the internet.** Providers take an injected `fetch` and are tested against recorded synthetic fixtures; the integration suites and Playwright run `ASSISTANT_PROVIDER=fake` (the integration helper refuses any other provider and checks the provider instance); the fake is refused with `NODE_ENV=production`. Only synthetic organizations (`it-*`, `e2e-portal-*`) were used.

### Playwright `assistant.spec.ts`

Seeded tenants (`tests/portal-e2e/seed/assistant.ts`): `e2e-portal-delta` with the assistant on (feature through the seed's operator path, tenant setting through the api with the acknowledgement), three policies and four messages (two held in quarantine); `e2e-portal-epsilon` with the feature on and the tenant setting off.

1. **Analyst:** the "AI assistant" navigation entry and the "Ask AI" button; `Ctrl/Cmd+J` opens and Escape closes the panel; the directive `/tool policy_management_list {"limit":2}` answered as `text/event-stream` with streamed text, a succeeded tool chip and a 2-row table card; "Load more" (`POST …/executions/{id}/more`) adds the third policy and hides the button; the demo intent "show active policies" gives a card with the two active policies only; axe; a row link opens `/policies/{id}` and closes the panel.
2. **Assistant page:** a demo intent over today's quarantine (2 rows), the URL follows the conversation, a new conversation, search by title, rename, clear with confirmation (`DELETE` → `204`), axe.
3. **Mailbox user** (no `assistant:use`): no button, no navigation entry, `Ctrl/Cmd+J` does nothing, `/assistant` shows "You do not have access to this page".
4. **Tenant setting off:** the organization admin sees "Ask AI (unavailable)", the reason "turned off for your organization" and the link to Settings → AI assistant (switch off), the same reason on `/assistant`, axe.
5. **Phone viewport (390 × 844):** the panel is a full-screen sheet, the card shows mobile rows, no horizontal overflow, axe.

The containerized api of the local stack runs with the assistant off (Compose passes no `ASSISTANT_*` key, `NODE_ENV=production`), so the run recreated the api with the e2e override and `tests/portal-e2e/assistant.override.yml` (`NODE_ENV=development`, `ASSISTANT_ENABLED=true`, `ASSISTANT_PROVIDER=fake`) and restored it afterwards. A stress rerun with `--repeat-each=3` hit the shipped per-user limit of 6 turns per minute (`429 rate_limited`) as designed; a normal run makes at most 3 turns per user.

## Not verified

- **Real LLM providers.** No call to Anthropic, OpenAI or Azure OpenAI was made (no key on this workstation by design); request and stream handling is covered by fixtures only. Answer quality, tool-selection accuracy and preserved-thinking replays against the live API remain to be checked once a key is provided (R9, R10).
- **Kubernetes and CI.** No cluster apply (ingress buffering of the event stream, egress policy, the AI-6 `api-assistant` Deployment) and no CI run.
- **Full regression suites.** By the product owner's process decision (2026-11-20) WP6 ran the repo checks and the targeted suites above, not the full `pnpm test:integration` chain or the full Playwright suite; the orchestrator gate runs the full Playwright suite (it must add `tests/portal-e2e/assistant.override.yml` when recreating the api, or the assistant spec's seed stops with a clear message).
- **Writes and confirmations** (AI-2 onward) do not exist yet.

## Fixes made after review round 1 (2026-11-21)

Details and the check results are in [the design note §13.2](../plan/steps/28-ai-chat-management.md#132-review-round-1-fixes-2026-11-21).

- **Retention:** a conversation used again after its content purge is purged again. Each turn sets a new `purge_after` and clears `content_purged_at`. The job re-checks candidates under a row lock. Lowering `retentionDays` moves existing purge dates earlier. Covered by unit tests and `apps/api/integration/assistant.test.ts`.
- **Loopback:** path parameter values `.`, `..` and `''` are refused (`denied_schema`). The built path must match the tool template, and the client refuses a path that URL resolution would change. Covered by `loopback-client.test.ts` and `tool-executor.service.test.ts`.
- **Untrusted data:** the evidence and explanation of ATO signals and the incident evidence, detail and notes are wrapped as `untrusted_text`. The generator now marks every free-form response value as untrusted, and the registry test fails if one is left uncovered. Registry version `fecb031f3ad52d84` → `30777563d395518a`. Covered by `results.test.ts` and `registry.test.ts`.
